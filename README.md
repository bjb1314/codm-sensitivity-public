# 手感刻度 · CODM

面向手机和平板玩家的《使命召唤手游》触控灵敏度参考工具。通过横屏靶场里的拖动、定位和跟枪测试，生成可以在游戏设置中填写的灵敏度起点。

## 功能

- 用手指拖动控制准星，碰到目标即可命中。
- 根据设备、指法、拇指行程和测试表现生成方案。
- 分别提供镜头和开火灵敏度，支持复制数值。
- 推荐在游戏中选择固定速度；数值为估算起点，可在训练场继续微调。
- 测试数据保存在当前浏览器中。

## 使用

下载 `手感刻度-CODM.html`，用手机、平板或电脑浏览器打开。手机和平板建议横屏使用。

## 源码

`codm-source.zip` 包含 TanStack Start、React、Tailwind CSS 和 Vite 项目源码，不包含依赖目录或构建产物。解压后安装 Node.js 和 npm，在源码目录运行：

```bash
npm install
npm run dev
```

按照终端显示的地址打开网页。开发检查可运行 `npm run typecheck`，构建使用 `npm run build`。
